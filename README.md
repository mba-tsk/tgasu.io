# Петербургские Истории

Веб-сайт, посвящённый культуре, истории и архитектуре Санкт-Петербурга.

## Описание

Проект представляет собой коллекцию подлинных рассказов о жизни, культуре и архитектуре Санкт-Петербурга — от основания города до наших дней.

## Структура проекта

```
├── index.html          # Главная страница
├── about.html          # Страница «О нас»
├── contacts.html       # Страница «Контакты»
├── stories.html        # Список всех историй
├── story1.html         # История #1
├── story2.html         # История #2
├── story3.html         # История #3
├── spb.css             # Таблицы стилей
├── images/             # Изображения
└── README.md           # Этот файл
```

## Технологии

- HTML5
- CSS3
- Адаптивный дизайн

## Запуск

Просто откройте `index.html` в любом современном браузере:

```bash
# Linux/Mac
xdg-open index.html     # Linux
open index.html         # Mac

# Windows
start index.html
```

Или используйте локальный веб-сервер:

```bash
python3 -m http.server 8000
```

Затем откройте в браузере: `http://localhost:8000`
